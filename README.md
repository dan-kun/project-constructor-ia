# Project Constructor IA

Agente inteligente para la creación asistida y auditada de estructuras de proyectos de software.

- Diseño completo: [`docs/DISENO.md`](docs/DISENO.md)
- Contexto para Claude Code: [`CLAUDE.md`](CLAUDE.md)

## Inicio rápido

```bash
pip install -e ".[dev]"
pytest
```

Configurar proveedor de IA en `config.yaml` (agnóstico: API, suscripción o modelo local vía Ollama).
